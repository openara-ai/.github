# openara.ai

# AI Systems

**Building AI systems through practical engineering.**

🌐 **Website:** https://openara.ai

openara.ai is an independent engineering, consulting, and research practice focused on building AI systems.

Our current work spans multimodal AI, model training and evaluation, local LLMs, efficient inference, and intelligent applications.

We use **agentic engineering** to shorten the **idea-to-production** cycle while maintaining **production-quality engineering**.

📖 Engineering stories and lessons learned are published in **[The Agentic Notes](https://theagenticnotes.substack.com)**.

---

# Projects

| Project | Description |
|---------|-------------|
| **[Media Search Agent](https://github.com/openara-ai/media-search-agent)** | Local-first multimodal AI system for searching personal photos and videos using semantic search, face recognition, object detection, metadata extraction, and video scene indexing. |
| **[MSA Ranker](https://github.com/openara-ai/msa-ranker)** | Learning and evaluation system for improving multimodal retrieval quality through ranking models, datasets, evaluation pipelines, and experimentation. |
| **[Finboard](https://github.com/openara-ai/finboard)** | Local-first AI system combining language models with deterministic tools for financial analysis and intelligent workflows. |
